### 4. CASES WHERE POSITIONAL INFORMATION CHANGES THE RESULT ###

Case 1: Query 'zip closure'
  Free-text VSM top result(s): ['D052', 'D022', 'D082', 'D012', 'D072']
  Exact phrase result(s):      []
  Explanation: The corpus contains 'zip fly' (Jeans) and 'button
  closure' (Shirts) but never the exact bigram 'zip closure'.
  Ordinary VSM still ranks jeans/shirts highly because 'zip' and
  'closure' both appear SOMEWHERE in those documents (bag-of-words
  co-occurrence is enough). The positional/phrase search correctly
  returns ZERO documents, because it requires the two terms to be
  adjacent in that exact order -- proving positional info is doing
  real work beyond plain term co-occurrence.

Case 2: Query 'cotton shirt'
  Free-text VSM top-5:  ['D001', 'D041', 'D061', 'D022', 'D082']
  Exact phrase matches: ['D001', 'D002', 'D021', 'D022', 'D041', 'D042', 'D061', 'D062', 'D081', 'D082']
  Proximity (k=3) matches: ['D001', 'D002', 'D011', 'D021', 'D022', 'D031', 'D041', 'D042', 'D051', 'D061', 'D062', 'D071', 'D081', 'D082', 'D091']
  Explanation: VSM ranks ALL documents mentioning both 'cotton' and
  'shirt' anywhere in the text (e.g. T-shirts where 'cotton' appears
  in one sentence and 'shirt' several words later), so its result
  set is larger and ordered purely by tf-idf weight, not adjacency.
  The exact-phrase search is strictly more precise: it only returns
  documents where 'cotton' is immediately followed by 'shirt', which
  removes false positives that only share vocabulary, not meaning.
  The proximity search (k=3) sits in between: it recovers documents
  where the two words are close together but not strictly adjacent,
  giving a superset of the phrase results and a subset of the VSM
   'anywhere in doc' results -- demonstrating the three techniques
  trade off precision vs recall differently.
